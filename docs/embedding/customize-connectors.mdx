If you would like to only show specific connectors to your embedding users, we recommend using **Connector Sets**.

## Connector Sets (recommended)

A connector set is a reusable, named selection of connectors (and, optionally, which of their actions/triggers are visible). You build the set once in the platform admin, give it a **Key**, then reference that key from your provision token.

<Steps>
    <Step title="Create a Connector Set">
        Go to **Platform Admin -> Setup -> Connectors -> Connector Sets**, create a set, choose which connectors are visible, and give it a **Key** (e.g. `premium`). If you leave the key blank, one is generated from the name.
    </Step>
    <Step title="Reference the set in the Provision Token">
        Issue a **v4** token and set the `connectorSet` claim to the set's key. Check how to generate a token in [provisioning users](./provision-users).

        ```json
        {
            /// Other claims
            "version": "v4",
            "connectorSet": "premium"
        }
        ```

        Each time the token is used by the embedding SDK, the token's project is assigned this connector set. If the key matches no set, the project falls back to the platform's default set.
    </Step>
</Steps>

## Tags (legacy)

Older integrations select connectors by tag using a **v3** token. New integrations should use connector sets instead.

<Steps>
    <Step title="Tag Connectors">
        Tag the connectors you would like to show to your user by going to **Platform Admin -> Setup -> Connectors**, selecting the connectors you would like to tag and hit **Apply Tags**

        ![Bulk Tag](../resources/screenshots/tag-connectors.png)
    </Step>
    <Step title="Add Tags to Provision Token">
       You need to specify the tags of connectors in the token, check how to generate token in [provisioning users](./provision-users).

        You should specify the `connectors` claim like this:
        ```json
        {
            /// Other claims
            "version": "v3",
            "connectorsFilterType": "ALLOWED",
            "connectorsTags": [ "free" ]
        }
        ```

        Each time the token is used by the embedding SDK, it will sync all connectors with these tags to the token's project. 
        The project will only contain the connectors that contain these tags.

        Only the **first** tag is honored, and it is matched against a connector set whose key equals the tag name.
    </Step>
</Steps>
