<Snippet file="enterprise-feature.mdx" />

This guide assumes you have already created a connector and created a private fork of our repository, and you would like to package it as a file and upload it.

<Tip>
Friendly Tip: There is a CLI to easily upload it to your platform. Please check out [Publish Custom Connectors](../misc/publish-connector).
</Tip>



<Steps>
    <Step title="Build Connector">
        Build the connector using the following command. Make sure to replace `${name}` with your connector folder name.

        ```bash
        npm run connectors -- build --name=${name}
        ```

        <Info>
        More information about building connectors can be found [here](../misc/build-connector).
        </Info>
    </Step>
    <Step title="Upload Tarball">
        Upload the generated tarball inside `dist/packages/connectors/${name}`from FEMA Integration Platform Platform Admin -> Connectors
    
        ![Manage Connectors](/resources/screenshots/install-connector.png)

    </Step>
</Steps>
