## Trigger

The workflow's starting point determines its frequency of execution. There are various types of triggers available, such as Schedule Trigger, Webhook Trigger, or Event Trigger based on specific service.

## Action

Actions come after the workflow and control what occurs when the workflow is activated, like running code or communicating with other services.
