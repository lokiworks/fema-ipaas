### Connector Authentication

FEMA Integration Platform supports multiple forms of authentication, you can check those forms [here](../connector-reference/authentication)

Now, let's establish authentication for this connector, which necessitates the inclusion of an API Key in the headers.

Modify `src/index.ts` file to add authentication,

```ts
import { ConnectorAuth, createConnector } from '@fema-ipaas/connectors-framework';

export const gelatoAuth = ConnectorAuth.SecretText({
  displayName: 'API Key',
  required: true,
  description: 'Please use **test-key** as value for API Key',
});

export const gelato = createConnector({
  displayName: 'Gelato',
  logoUrl: 'https://cdn.fema.local/connectors/gelato.png',
  auth: gelatoAuth,
  authors: [],
  actions: [],
  triggers: [],
});
```

<Note>
  Use the value **test-key** as the API key when testing actions or triggers for
  Gelato.
</Note>
