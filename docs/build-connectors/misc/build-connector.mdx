You can use the CLI to build custom connectors for the platform. This process compiles the connectors and exports them as a `.tgz` packed archive.

### How It Works

The CLI scans the `packages/connectors/` directory for the specified connector. It checks the **name** in the `package.json` file. If the connector is found, it builds and packages it into a `.tgz` archive.

### Usage

To build a connector, follow these steps:

1. Ensure you have the CLI installed by cloning the repository.
2. Run the following command:

```bash
npm run build-connector
```

You will be prompted to enter the name of the connector you want to build. For example:

```bash
? Enter the connector folder name : google-drive
```

The CLI will build the connector and you will be given the path to the archive. For example:

```bash
Connector 'google-drive' built and packed successfully at packages/connectors/community/google-drive/dist
```

You may also build the connector non-interactively by passing the connector name as an argument.  For example:
```bash
npm run build-connector google-drive
```
