This platform is self-hosted first: there is no managed environment where secrets, keys or env vars arrive pre-provisioned. Any feature needing a new env var, secret, key, connector auth method, or DB extension must default to **zero setup** — never ship something that looks enabled in the UI but is silently broken until an operator sets a variable by hand.
Corollary: an unset optional integration (template registry, connector registry, SMTP) must degrade to an empty/disabled state, not an error.
