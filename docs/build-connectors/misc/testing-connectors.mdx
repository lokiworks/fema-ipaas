Testing connectors is **optional** but recommended for complex logic. Connectors can be tested using [Vitest](https://vitest.dev/) with the `createMockActionContext` helper from the framework.

For a full working example, see the [text-helper connector tests on GitHub](https://github.com/lokiworks/fema-ipaas/tree/main/packages/connectors/core/text-helper/test).

## Setup

### 1. Add vitest to your connector

Add `vitest` as a dev dependency in your connector's `package.json` and add a `test` script:

```json
{
  "scripts": {
    "build": "tsc -p tsconfig.lib.json && cp package.json dist/",
    "lint": "eslint 'src/**/*.ts'",
    "test": "vitest run"
  },
  "devDependencies": {
    "vitest": "3.0.8"
  }
}
```

### 2. Create a vitest config

Create `vitest.config.ts` in your connector root:

```typescript
import path from 'path'
import { defineConfig } from 'vitest/config'

const repoRoot = path.resolve(__dirname, '../../../..')

export default defineConfig({
  test: {
    globals: true,
    environment: 'node',
  },
  resolve: {
    alias: {
      '@fema-ipaas/shared': path.resolve(repoRoot, 'packages/core/shared/src/index.ts'),
      '@fema-ipaas/connectors-framework': path.resolve(repoRoot, 'packages/connectors/sdk/src/index.ts'),
      '@fema-ipaas/connectors-common': path.resolve(repoRoot, 'packages/connectors/common/src/index.ts'),
    },
  },
})
```

### 3. Write tests

Create a `test/` directory and add `.test.ts` files:

```typescript
import { createMockActionContext } from '@fema-ipaas/connectors-framework';
import { myAction } from '../src/lib/actions/my-action';

describe('myAction', () => {
  test('does something', async () => {
    const ctx = createMockActionContext({
      propsValue: {
        inputField: 'test value',
      },
    });

    const result = await myAction.run(ctx);
    expect(result).toBe('expected output');
  });
});
```

### 4. Run tests

```bash
# Run tests for a specific connector
npx turbo test --filter=@fema-ipaas/connector-text-helper

# Run tests directly from the connector directory
cd packages/connectors/core/text-helper
npx vitest run
```
