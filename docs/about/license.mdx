FEMA Integration Platform is released under the [MIT license](https://github.com/lokiworks/fema-ipaas/blob/main/LICENSE).

There is no enterprise edition, no commercial tier, and no feature that requires a paid licence. Every capability in this repository is available to every self-hosted instance. Instance-wide caps live in `SYSTEM_LIMITS` and per-workspace caps live on the workspace row; neither is a paywall.

This is a deliberate departure from the upstream project this fork started from, which split its code between an MIT core and a commercially licensed `packages/ee` directory. That directory and its licence do not exist here — see [ADR 0002](https://github.com/lokiworks/fema-ipaas/blob/main/docs/adr/0002-remove-enterprise-edition.md).

Attribution for the upstream work this fork builds on is in [NOTICE.md](https://github.com/lokiworks/fema-ipaas/blob/main/NOTICE.md).
