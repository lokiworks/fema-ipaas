The Bull Board is a tool that allows you to check issues with scheduling and internal workflow runs issues.

![BullBoard Overview](https://raw.githubusercontent.com/felixmosh/bull-board/master/screenshots/overview.png)

## Setup BullBoard

To enable the Bull Board UI in your self-hosted installation:

1. Define these environment variables:
   - `FEMA_QUEUE_UI_ENABLED`: Set to `true`
   - `FEMA_QUEUE_UI_USERNAME`: Set your desired username
   - `FEMA_QUEUE_UI_PASSWORD`: Set your desired password

2. Access the UI at `/api/ui`


<Tip>
For cloud installations, please ask your team for access to the internal documentation that explains how to access BullBoard.
</Tip>

## Queue Overview

We have one main queue called `workerJobs` that handles all job types. Each job has a `jobType` field that tells us what it does:

### Low Priority Jobs

#### RENEW_WEBHOOK
Renews webhooks for connectors that have webhooks channel with expiration like Google Sheets.

#### EXECUTE_POLLING
Checks external services for new data at regular intervals.

### Medium Priority Jobs

#### EXECUTE_WORKFLOW
Runs workflows when they're triggered.

#### EXECUTE_WEBHOOK
Processes incoming webhook requests that start workflow runs.

#### DELAYED_WORKFLOW
Runs workflows that were scheduled for later, like paused workflows or delayed executions.

### High Priority Jobs

#### EXECUTE_PROPERTY
Loads dynamic properties for connectors that need them at runtime.

#### EXECUTE_EXTRACT_CONNECTOR_INFORMATION
Gets information about connectors when they're being installed or set up.

#### EXECUTE_VALIDATION
Checks that workflow settings, inputs, or data are correct before running.

#### EXECUTE_TRIGGER_HOOK
Runs special logic before or after triggers fire.


<Info>
Failed jobs are not normal and need to be checked right away to find and fix what's causing them. 
They require immediate investigation as they represent executions that failed for unknown reasons that could indicate system issues.
</Info>

<Tip>
Delayed jobs represent either paused workflows scheduled for future execution, upcoming polling job iterations, or jobs being retried due to temporary failures. They indicate an internal system error occurred and the job will be retried automatically according to the backoff policy.
</Tip>
