You can use the CLI to publish custom connectors to the platform. This process packages the connectors and uploads them to the specified API endpoint.

### How It Works

The CLI scans the `packages/connectors/` directory for the specified connector. It checks the **name** and **version** in the `package.json` file. If the connector is not already published, it builds, packages, and uploads it to the platform using the API.

### Usage

To publish a connector, follow these steps:

1. Ensure you have an API Key. Generate it from the Admin Interface by navigating to Settings.
2. Install the CLI by cloning the repository.
3. Run the following command:

```bash
npm run publish-connector-to-api
```

4. You will be asked three questions to publish your connector:

  - `Connector Folder Name`: This is the name associated with the folder where the action resides. It helps organize and categorize actions within the connector.

  - `API URL`: This is the URL of the API endpoint where the connector will be published (ex: https://github.com/lokiworks/fema-ipaas/api).

  - `API Key Source`: This is the source of the API key. It can be either `Env Variable (FEMA_API_KEY)` or `Manually`.


In case you choose `Env Variable (FEMA_API_KEY)`, the CLI will use the API key from the `.env` file in the `packages/server/api` directory.

In case you choose `Manually`, you will be asked to enter the API key.


Examples:

```bash
npm run publish-connector-to-api

? Enter the connector folder name : google-drive
? Enter the API URL : https://github.com/lokiworks/fema-ipaas/api
? Enter the API Key Source : Env Variable (FEMA_API_KEY)

```

```bash
npm run publish-connector-to-api

? Enter the connector folder name : google-drive
? Enter the API URL : https://github.com/lokiworks/fema-ipaas/api
? Enter the API Key Source : Manually
? Enter the API Key : ap_1234567890abcdef1234567890abcdef

```
