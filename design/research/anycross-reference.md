# 飞书集成平台（AnyCross）交互参考

这是做原型前对飞书集成平台的调研摘要，调研时间 2026-09。原型里「照 AnyCross 来做」的依据都在这里。数据集成部分不在范围内，没有整理。

飞书集成平台的对外品牌叫 **AnyCross**，控制台在 `anycross.feishu.cn/console`，文档中心在 `anycross.feishu.cn/documentation`。

**资料来源与可信度**：

- 官方文档正文，以及文档里 2023–2025 年的截图。
- 控制台前端公开的中文文案包，按钮和字段的原文以它为准。

标了「推断」的内容是没有直接证据、按飞书通用设计补的。

新版和旧版的术语不同，原型用的是新版：

| 旧版 | 新版 | 原型里的叫法 |
| --- | --- | --- |
| 集成流 | 工作流 | 工作流 |
| 连接 | 应用凭证 | 连接（沿用本仓库词汇） |
| 变量 | 项目配置 / 配置组 | 项目配置 |

## 1. 全局结构

**层级**：企业（租户）→ 项目 → 资源（工作流、数据存储、文件夹），没有「空间」「团队」这一层。

- 项目是最小的权限单元，项目角色是：所有者、可编辑（可查看和编辑项目）、可查看（仅可查看项目）。
- 应用凭证不属于项目，归个人所有，可以分享给别人，权限是：可编辑、可阅读（可查看和使用凭证）。

**左侧主导航**：一条约 56px 宽的深色图标栏。

- 上半部分是当前模块的入口。以业务集成为例：业务集成、运行日志、应用凭证管理。
- 底部依次是：教程、文档、方案、设置、模块切换（九宫格）、头像。
- 图标下面有小字标签，悬停时出现深色提示条。

**模块切换**：浮层标题是「切换功能模块」，里面是彩色大图标网格：业务集成、身份集成、本地代理服务、连接器、服务商。

**全局入口**：全局搜索（提示「共 # 个搜索结果」）、通知中心、个人中心。

**首页**：

- 新手引导分两步：创建集成项目、创建工作流；可以「从模板新建工作流」并「换一批」。
- 最近访问：资源名、所属项目、所有者、最近修改时间。
- 我的项目。
- 新手引导浮层的按钮：开始新手引导、暂时跳过。

**空项目的落地页**：左边插画；右边是标题「业务集成」、三条要点和「+ 新建工作流」按钮；底部是「从模板新建工作流 ⟳ 换一批」，一排 4 张模板卡片。

## 2. 项目侧栏（工作流列表）

新版没有独立的工作流表格页，工作流挂在项目的二级侧栏里（约 260px 宽）。侧栏从上到下：

1. 「当前项目」小字，右边一个 ···。
2. 项目卡片：彩色方块头像 + 项目名 + ▾。
   - 下拉里有搜索框和「我的项目」分组。
   - 底部两个入口：新建项目、全部项目。
3. 两个菜单项：项目配置、数据存储。
4. 标题「项目资源(N)」和一个 +。
   - + 菜单：新建工作流、导入工作流（ZIP）、新建文件夹。
5. 搜索框「搜索工作流名称」。
6. 工作流列表：工作流图标角上有状态圆点，绿色表示运行中，灰色表示未运行。

**项目 ··· 菜单**：项目概览、分享、编辑基本信息、更改项目图标、删除、新建项目、创建副本、查看全部项目。

**工作流 ··· 菜单**：发布、启动工作流、基本信息、创建副本（可以复制到其他项目）、导出、查看日志、移动到文件夹、删除。没有发布过版本时，「启动」置灰，提示「工作流尚未发布版本，无法启动」。

**文件夹**：最多三层，每个项目最多 100 个。可以拖拽排序、拖入文件夹，也可以展开或收起全部。

**批量操作**：点「批量操作」后出现复选框，提示「已选择 N 个资源」，可以批量发布、批量删除、批量移动。批量发布是三步向导：

1. 校验资源：不可发布的会被自动移出。
2. 发布配置：选配置组，写发布描述。
3. 发布结果：「本次共批量发布 N 个资源，X 个可发布，Y 个不可发布」。

**新建工作流弹窗**，从上到下：

- 工作流名称（100 字，带计数）。
- 描述（300 字）。
- 选择触发器：两列卡片，选中后右上角出现三角勾。卡片有：网址触发器、手动触发器、定时任务、子流程触发器、告警触发器。
- 「或选择应用事件触发流程运行」：一排应用图标。

创建后先进入只读预览，点右上角「编辑」才开始编辑。

## 3. 工作流编辑器

**画布**：纵向自上而下的流程图，不是自由画布。背景是浅灰点阵，所有面板都浮在画布上。

**节点**：约 56px 的圆角方块图标，右边两行字：第一行是节点名（粗体），第二行是节点 ID（灰色小字，如 `webhook-trigger-1`、`bitable-1`、`script-1`）。

- 连线是带箭头的竖线，线中点有一个 +。
- 选中的节点蓝色描边，配置有错的节点粉红色描边。
- 分支横向展开，线上用灰字标分支名。

**顶栏**：

- 左边：工作流图标、名称 ▾（切换工作流）、✎（重命名）、状态标签（未运行 / 运行中）。
- 左边第二行：「最后更新时间：…」，有未发布的修改时显示「有更新未发布」。
- 右边（查看态）：···、编辑、发布。
- 右边（编辑态）：···、调试、完成。

**左侧浮动工具条**：连接器（节点面板，可以拖到画布上）、日志（调试记录）、校验（带红色角标）、项目配置、数据存储、搜索。

**其他控件**：左下角是撤销和重做；右下角是缩放和缩略图。另有重置视图、全屏、展开或折叠全部节点。

**添加节点**：点连线上的 +，或者从连接器面板拖到画布上。

- 节点面板顶部是搜索框，下面是 Tab（逻辑、助手、飞书、业务，另有 AI），内容是三列图标网格。
- 选中连接器后再选操作，操作按分组列出，可以搜索。

**节点类型**：

- 触发器：网址（异步 / 同步）、手动、定时、子流程、告警、各应用的事件。
- 逻辑：分支、循环、While 循环、延迟、终止、同步网址触发回调、调用子流程、子流程响应。
- 助手：时间日期、消息卡片、加解密、字符串、列表、Object、JSON、文件、邮件、XML、CSV、随机数、HTTP Client、动态脚本（JavaScript / Python）、设置变量、数据存储、数据转换。
- AI：各家大模型的连接器。
- 应用：飞书各产品和业务系统的连接器。

**右侧配置面板**：浮动白卡片，约 330px 宽，头部是图标、标题、「操作：xxx」副标题、? 帮助、✕。Tab 随节点类型变化，有错的 Tab 右上角带红点：

| 节点类型 | Tab |
| --- | --- |
| 连接器动作 | 操作 / 凭证 / 入参 / 出参 / 错误处理 |
| 助手 | 操作 / 入参 / 出参 / 错误处理 |
| 网址触发器 | 触发器 / 设置 / 出参 / 测试 |
| 手动触发器 | 触发器 |

- **操作 Tab**：搜索框 + 按分组折叠的操作卡片；选中的卡片是浅底色加右上角三角勾。
- **入参**：每个参数一行，左侧有一个圆圈（用来连线取值），参数名后是 * 和 ⓘ；右侧是取值方式切换（Aa / 123 / 对象 / Ex）。校验不通过时输入框红框，下方红字「xx是必填项」。
- **面板底部**：「版本号 x.y ▾」，可以切换连接器版本。停止维护的版本会有提示。

**数据引用**：

- **连线取值**：从入参左侧的圆圈拖一条彩色曲线到上游节点，节点旁弹出出参树，选中属性即可。
  - 出参树每行是类型图标 + 「字段名 (中文说明)」。
  - 只能引用上游节点，不同分支之间不能互相取值。
- **胶囊**：引用生成的数据块。点击胶囊可以编辑、复制或删除。
- **表达式模式（Ex）**：输入 `$` 唤出数据，在数据后输入 `.` 唤出函数，最多 1000 字符。

**各节点的专属配置**：

- **定时任务**：
  - 触发方式：每天、按周、按月、仅一次、间隔。按月可以指定日期、每月第一天、最后一天、第一个或最后一个工作日。
  - 间隔触发可选「发布后触发一次 / 发布后不触发」。
  - 时区；生效期默认发布后两年。
  - 可以跳过法定节假日、跳过休息日。
- **网址触发器**：
  - 设置：只读的回调地址（可复制）、Body 类型（JSON / Text）、鉴权方式、IP 白名单。
  - 测试：「获取数据并预览」，结果可以「应用为出参」或「保存为出参数据」。
- **分支**：
  - 类型分互斥分支（从左到右依次判断）和并行分支。
  - 条件写成「符合以下 所有 / 任意 条件」+ 左值、运算符、右值。
  - 每个分支可以加一个 AI 条件。
- **循环**：串行或并行，设置最大并行数量；出参有循环变量、下标、上下文。
- **错误处理**：
  - 先设默认策略（终止），再加若干条自定义策略。每条策略的内容：按 Code 等于任一 / 不等于任一 / 以任一开头 / 不以任一开头来匹配，再选处理策略（终止、忽略、添加分支、重试后终止、重试后忽略、重试后添加分支）。
  - 策略从上往下匹配，命中一条即停止。
  - 「一键应用」可以把策略应用到同类节点。

**校验、调试、发布**：

- **校验面板**：实时列出错误和警告，点一条定位到节点。有错误时不能调试，也不能发布（提示「部分错误尚未修正，无法调试」）。
- **调试弹窗**：
  - 字段「配置调试出参信息 *」，是一个 JSON 编辑器，带「生成默认出参 / 清除 / 全屏编辑」。
  - 工作流用到项目配置时，还要选配置组。
- **调试结果面板**：在画布左侧，可以拖边框调大小。
  - 顶部是「调试记录：[时间 ▾]」、耗时、运行信息；下面可以按节点状态和关键词筛选。
  - 左栏是节点列表，右栏是开始 / 结束时间、运行时长和 Input / Output / Error。
  - 工具按钮：使用输出、复制、放大、画布定位。
  - 运行中可以「终止调试」。
- **保存**：编辑态自动保存，页面显示「最后更新时间」。
- **发布弹窗**：
  - 内容：选配置组，写发布描述。
  - 提示：「发布后，工作流将开始运行。若当前工作流正在运行，则新发布的工作流将覆盖原有运行，请慎重操作。」
  - 有警告时先弹「发布提醒 · 继续发布」。
  - 成功提示「发布成功，工作流开始运行」，发布即启用。
- **停止工作流**：需要确认，提示「确认停止运行？停止后的工作流将不可使用，请谨慎操作」。
- **版本管理**：列表显示版本号、发布时间、版本描述、发布人；可以打开快照（只读画布）；没有一键回滚。
- **剪贴板**：可以复制、剪切、粘贴节点（粘到选中节点上方或下方），也可以跨工作流、跨项目粘贴，粘贴后引用会自动修正。

**使用限制**：

| 项 | 上限 |
| --- | --- |
| 单个工作流节点数 | 200 |
| 嵌套层数 | 10 |
| 单次运行时长 | 4 小时 |
| 单节点运行时长 | 60 秒 |
| 单节点出入参合计 | 4 MB |
| 租户并发运行的工作流 | 100 |

## 4. 运行日志

**列表页**：

- 顶部：「① 筛选」药丸按钮（数字是已设条件数）和「刷新」；下面一行条件摘要，比如「符合全部筛选条件：[近 24 小时日志]」。
- 表格列：日志产生时间、工作流名称（链接）、所属项目、类型（运行日志 / 调试日志）、发布版本、运行状态（圆点 + 文字）、运行时长、错误数、操作（日志详情 · 重试）。「重试」只在失败的行出现。
- 分页：「共 N 条 ‹ 1 2 … › 10 条/页 跳至 _ 页」。

**筛选浮层**：

- 右上角可以选「符合以下 全部 / 任一 条件」。
- 每条条件是：字段 + 运算符 + 值 + ✕。字段有时间、项目、工作流、运行状态、连接器、日志内容、运行时长。
- 时间预设：近 15 / 30 分钟、24 小时、3 / 7 / 15 / 30 天。
- 只能查 30 天内的日志。

**日志详情**：从右侧滑出的大抽屉，约占 80% 宽度。

- 标题「时间 | 工作流名 [Flow]」，下一行是状态、耗时和运行信息。
- 内容：节点列表，加 Input / Output / Error。
- 出错时显示错误信息和排查建议，可以跳到上一个 / 下一个错误。

**重试**：确认框提示「重试后，将重新触发最新已发布的工作流并生成新日志」，按钮是「仅重试 / 重试并跳转」。重试生成的日志带「xx 手动重试生成」标记。

**终止运行**：可以勾选「同时停止子流程」。

## 5. 应用凭证（原型里叫「连接」）

**列表页**：搜索框，「连接的应用 ▾」「状态 ▾」两个筛选，右上角「+ 新建应用凭证」。表格列是：名称（带应用图标）、状态（●已连接 / 未连接）、所有者、最后更新时间、操作（编辑凭证 · 分享 · ···）。

**新建弹窗**：

- 字段：要连接的应用、凭证名称（30 字）。
- 飞书应用还要选：
  - 认证类型：应用授权 / 用户授权。
  - 应用凭证：「选择飞书应用获取凭证」或「输入凭证」（App ID / App Secret）。
- 按钮：仅创建、创建并连接。
- 用户授权：多一个重定向 URL（可复制），并提示「请先将重定向 URL 添加到安全设置」。
- 连接失败：弹出「凭证连接发生错误，请重试」，附错误信息和「复制信息」按钮。

**删除**：列出后果，并要求输入凭证名确认。

**在节点里使用**：选好凭证后，可以「更新使用同类凭证的节点」，批量套用。飞书凭证还会检查应用权限，缺权限时给出「去配置」入口。

## 6. 模板

**分类**：团队协作、人力资源、审批协同、项目管理、市场营销、电商物流、客户关系、开发工具、AI 等。

**模板卡片**：顶部是连接器图标链「触发器 ▸ 动作 动作」，下面是标题、描述，分隔线下是标签。

**从模板新建**：

- 弹窗 Tab：推荐、我的模板、与我共享。
- 流程：使用此模板 → 选择目标项目 → 「从模板新建成功」→ 进入编辑器，校验面板提示补全凭证。

**生成模板**：填模板名称、描述、帮助文档链接，选择分享到组织内或分享到互联网。凭证、项目配置和日志不会被分享。

## 7. 运行监控与告警

**运行监控**：

- 视图：支持多视图，可以另存为视图、保存变更、重置视图。
- 筛选：时间范围（15 分钟到 30 天）、项目、工作流。
- 指标：运行次数，成功 / 失败 / 终止的次数和占比，运行中工作流数，运行节点数，并发数。
- 图表：运行趋势图、运行状态分布。
- 数据明细：按工作流列出。

**告警**：不是独立的配置页，而是用「告警触发器」开头的工作流来实现。

- 告警触发器的配置：
  - 规则名称。
  - 事件：异常事件（流程运行失败等）或阈值事件（失败率、超时、CPU / 内存）。
  - 资源范围、告警频率、持续周期、生效时段。
- 告警触发器后面接一个消息节点，把告警发出去。

## 8. 连接器开发

1. **入口**：空态是「Hi，创建你的第一个连接器」加「+ 新建连接器」按钮。
2. **新建向导**（两步）：
   - 第一步「选择要集成的服务」：平台预置 / 自定义，首格是「+ 新建」。
   - 第二步「填写基本信息」：图标、名称、标识符（保存后不可修改）、说明。
3. **工作区左栏**：
   - 顶部：当前连接器 ▾，下面是最近保存时间。
   - 导航：基础信息（未完成时带红点）、认证与授权、版本与发布。
   - 「操作 +」：新建操作、新建分组、新建触发器；下面是状态码配置和分组树。
4. **基础信息**：由几张卡片组成，每张右上角有「编辑」：
   - 名称、说明和帮助文档。
   - 基础路径：未填时标「待配置」。
   - 可用范围、开发者成员、国际化。
5. **认证**：
   - 类型：授权码（OAuth2Code）、客户端凭证、API Key、Basic Auth。创建后不能改类型。
   - 开发认证分五步：基础信息 → 认证表单 → 认证流程 → 测试认证 → 发布认证。只有测试全部通过才能发布，发布后不能撤回。
6. **操作编辑**：
   - Tab：基本信息、入参、出参、API 配置、状态码。
   - 右侧一直显示「模拟器」，实时预览这个操作在工作流面板里的样子。
   - 入参支持动态下拉（默认值来自 HTTP 接口）、正则校验和可见性表达式。
   - API 配置里用 `{{input.x}}` 插值，请求体支持 none / form-data / x-www-form-urlencoded / JSON。
7. **触发器**：分两种。
   - 即时触发器：配置订阅端点、取消订阅端点、执行端点。
   - 轮询触发器：配置分页规则、排序、主数据路径、去重标识、检查点变量。
8. **调试台**：填调试参数、选择凭证；结果分请求、响应、HTTP 日志三部分，可以保存记录。
9. **版本与发布**：
   - 发布是全屏两步：确认发布变更（左边勾选，右边看变更前后对比）→ 填写发布信息（发布新版本，或在当前版本中发布更新）。
   - 版本状态：灰度中、全量发布、停止支持。
   - 发布后可以申请上架到集成市场。

## 9. MCP 服务

1. **服务列表**：Tab 是全部服务、我开发的、我获取的。类型分平台官方和企业自定义；状态有已启用、已暂停、待发布。
2. **创建服务**：填服务名称、唯一标识、描述、图标。
3. **新建工具**：
   - 从连接器新建：选择连接器 → 选择操作 → 确认信息。
   - 从工作流新建：选择项目 → 选择已发布的工作流 → 确认信息。
4. **工具配置**：名称、描述；入参可以设为「AI 推断字段」、引用值、默认值，或取客户端上下文。
5. **凭证配置方式**：三选一——开发者配置的固定凭证、由服务使用者配置、由使用 MCP 的用户授权。
6. **使用方式**：服务地址和 API Key（可以重置），附接入 aily、Cursor、Trae 等客户端的配置，有「复制全部」按钮。
7. **其他**：问题检查（错误数和警告数）、调试、发布记录、可用范围、上架到 MCP 市场。

## 10. 设置

- **用户管理**：「+ 添加用户」一次最多 10 人，同时分配功能模块权限（业务集成默认拥有，不能取消），可以勾选「发送通知」。列表列是用户、用户状态、模块权限、操作（编辑 / 禁用 / 移除）。
- **权限高级设置**：
  - 无权限提示：显示最近 2 位管理员 / 指定人员 / 网址 / 申请入口，右侧有页面示意。
  - 审核方式：在平台中审核，或在飞书审批中审核。
- **集成资源管理**：按资源名、类型、所有者筛选；可以单个或批量转移所有权，主要用于离职交接。
- **权益管理**：显示当前周期运行次数，并按项目给出明细，可以配置容量告警通知。原型去掉了其中的付费部分。
- **AnyCross 没有公开页面的**：审计日志、租户级 IP 白名单、租户级全局变量。

## 11. 视觉与交互习惯

- **弹窗与抽屉的分工**：
  - 新建类操作用弹窗。
  - 查看详情用右侧大抽屉。
  - 编辑器里的配置用浮动面板。
  - 多步发布用全屏页。
  - 长流程用步骤条。
- **Tab**：一律下划线样式，有错时带红点。
- **表单**：必填项标红色 *，文本框右下角有字数计数（如 0/100）；选择型卡片选中时是主色描边加右上角三角勾。
- **状态展示**：彩色圆点加文字；行操作用主色文字链接。
- **危险操作**：二次确认，删除关键资源要输入名称确认。
- **提示**：操作结果用顶部居中的轻提示，比如「发布成功，工作流开始运行」「已复制到剪贴板」。
- **新手引导**：聚光灯 + 步骤卡片，按钮是「退出教程 / 下一步」。
